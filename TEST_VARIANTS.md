# Тестовые скрипты для проверки обхода блокировки Ozon

Создано 5 вариантов скриптов с разными подходами к обходу детекта автоматизации.

## Варианты

### test_unblock_v1.py — Минимальная автоматизация
**Подход:** Открывает браузер с профилем, НЕ делает автоматических переходов.
**Как работает:** Пользователь сам открывает вкладку и вводит ozon.ru вручную.
**Для чего:** Базовая проверка — работает ли профиль без автоматизации вообще.
**Запуск:** `uv run test_unblock_v1.py`

### test_unblock_v2.py — Прямое открытие URL
**Подход:** Открывает браузер сразу на ozon.ru через аргумент командной строки.
**Как работает:** Передаёт URL в args при launch_persistent_context.
**Для чего:** Избегает промежуточных about:blank и page.goto().
**Запуск:** `uv run test_unblock_v2.py`

### test_unblock_v3.py — Без очистки cookies
**Подход:** НЕ очищает cookies перед разблокировкой, сохраняет сессию.
**Как работает:** 
- Открывает страницу с блокировкой
- Ждёт 5 минут
- Открывает НОВУЮ вкладку БЕЗ очистки cookies
- Переходит на ozon.ru через window.location
**Для чего:** Проверка, помогает ли сохранение сессии обойти блокировку.
**Запуск:** `uv run test_unblock_v3.py`

### test_unblock_v4.py — Максимально человеческое поведение
**Подход:** Имитирует активность реального пользователя перед переходом на Ozon.
**Как работает:**
- Сначала открывает Google (разогрев)
- Имитирует движения мыши и скроллинг
- Переходит на Ozon через Ctrl+L и посимвольный ввод
**Для чего:** Максимальная имитация человека — активность, задержки, естественные переходы.
**Запуск:** `uv run test_unblock_v4.py`

### test_unblock_v5.py — Подключение к существующему браузеру
**Подход:** Подключается к УЖЕ запущенному браузеру через CDP.
**Как работает:**
1. Сначала вручную запускаете chromium с отладочным портом:
   ```bash
   chromium --remote-debugging-port=9222 --user-data-dir=/home/ivans/monitor_price_bot/user_data/1189033386
   ```
2. Затем запускаете скрипт, который подключается к этому браузеру
**Для чего:** Браузер запущен вручную (не автоматизацией), скрипт только подключается.
**Запуск:** 
```bash
# Терминал 1:
chromium --remote-debugging-port=9222 --user-data-dir=/home/ivans/monitor_price_bot/user_data/1189033386

# Терминал 2:
uv run test_unblock_v5.py
```

## Рекомендации по тестированию

1. **Начните с v1** — проверьте, что профиль вообще работает без автоматизации
2. **Попробуйте v3 и v4** — они используют разные стратегии навигации
3. **v5 — последняя надежда** — если всё остальное не работает, браузер запущен вручную

## Все скрипты сохраняют скриншоты в `debug_data/`

После каждого теста проверяйте скриншоты для анализа результата.
