# Тестовый скрипт парсинга корзины Ozon

## Описание

Скрипт автоматически парсит корзину Ozon каждые 1-2 часа в рандомное время и сохраняет результаты в файлы.

## Требования

- Chrome должен быть запущен с remote debugging на порту 9222
- В корзине Ozon должны быть товары

## Запуск

### 1. Запустить Chrome с remote debugging

**Локально:**
```bash
chromium --remote-debugging-port=9222 --user-data-dir=/home/ivans/.config/chromium
```

**На сервере (через xvfb-run):**
```bash
xvfb-run -a chromium --remote-debugging-port=9222 --user-data-dir=/home/ivans/.config/chromium
```

### 2. Открыть корзину Ozon вручную

В запущенном Chrome перейди на https://www.ozon.ru/cart и авторизуйся (если нужно).

### 3. Запустить скрипт

**Локально:**
```bash
python scripts/test_cart_parser.py
```

**На сервере (в фоне):**
```bash
nohup python scripts/test_cart_parser.py > cart_parser.log 2>&1 &
```

## Результаты

Результаты сохраняются в директорию `cart_results/`:

- `cart_YYYYMMDD_HHMMSS.txt` — текстовый файл с товарами и ценами
- `cart_YYYYMMDD_HHMMSS.png` — скриншот корзины

### Пример файла результатов:

```
Дата и время: 2026-05-27 13:30:45
Всего товаров: 2
================================================================================

1. Gazpromneft Premium N 5W-40 Масло моторное, Синтетическое, 4 л
   Цена: 2311 ₽

2. Лосьон для роста волос и бороды 5%, средство против выпадения и облысения
   Цена: 874 ₽
```

## Логика работы

1. Подключается к Chrome через CDP (порт 9222)
2. Применяет stealth-патчи для обхода детекта
3. Переходит на https://www.ozon.ru/cart
4. Парсит все товары (название + цена со скидкой)
5. Сохраняет результаты в файл с timestamp
6. Ждёт рандомное время (1-2 часа + рандомные минуты/секунды)
7. Повторяет цикл

## Остановка скрипта

**Если запущен в терминале:**
```bash
Ctrl+C
```

**Если запущен в фоне:**
```bash
# Найти PID процесса
ps aux | grep test_cart_parser.py

# Убить процесс
kill <PID>
```

## Селекторы для парсинга

- **Блок товара:** `div.checkout_s6`
- **Название:** `span.tsCompact500Medium`
- **Цена со скидкой:** `div.checkout_t span.tsHeadline400Small` (первая)
- **Старая цена:** `span.tsBodyAccent300XSmall` (зачёркнутая)

## Troubleshooting

**Ошибка "Не удалось подключиться к Chrome":**
- Убедись, что Chrome запущен с `--remote-debugging-port=9222`
- Проверь, что порт 9222 свободен: `lsof -i :9222`

**Нет товаров в результатах:**
- Проверь скриншот в `cart_results/`
- Убедись, что в корзине есть товары
- Возможно, Ozon изменил структуру HTML — проверь селекторы

**Chrome закрывается:**
- Не закрывай Chrome вручную во время работы скрипта
- Скрипт только подключается к Chrome, не управляет его жизненным циклом
