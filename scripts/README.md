# Скрипты авторизации

## authorize_user.py

Скрипт для авторизации пользователей через QR-код Ozon.

### Как это работает

1. **Пользователь запрашивает авторизацию:**
   - Отправляет команду `/login` боту
   - Вводит номер телефона в формате `+79991234567`
   - Запрос сохраняется в БД

2. **Администратор получает уведомление:**
   - Бот отправляет админу сообщение с данными пользователя
   - Админ нажимает кнопку "✅ Авторизовать" или "❌ Отклонить"

3. **Процесс авторизации (при одобрении):**
   - Открывается браузер с профилем `user_data/{user_id}/`
   - Админ вручную:
     - Переходит на страницу входа Ozon
     - Вводит номер телефона пользователя
     - Ждёт появления QR-кода
   - Скрипт автоматически:
     - Делает скриншот QR-кода
     - Отправляет его пользователю в Telegram
     - Ждёт завершения авторизации (проверка cookies)
     - Закрывает браузер
     - Уведомляет пользователя и админа о результате

4. **Использование профиля:**
   - После успешной авторизации профиль сохраняется в `user_data/{user_id}/`
   - При парсинге товаров бот автоматически использует профиль пользователя
   - Если профиль не найден — используется системный профиль

### Структура профилей

```
user_data/
├── {user_id_1}/          # Профиль пользователя 1
│   └── Default/
│       ├── Cookies
│       ├── Local Storage
│       └── ...
├── {user_id_2}/          # Профиль пользователя 2
│   └── Default/
│       └── ...
└── user_data/            # Системный профиль (fallback)
    └── Default/
        └── ...
```

### Проверяемые cookies для авторизации

Скрипт проверяет наличие следующих cookies Ozon:
- `abt_data`
- `__Secure-access-token`
- `ADDRESSBOOKBAR_NEW_ADDRESS_ADDED`

### Таймауты

- **Ожидание QR-кода:** 120 секунд (2 минуты)
- **Ожидание авторизации:** 120 секунд (2 минуты)

### Обработка ошибок

- **TimeoutError:** Пользователь не завершил авторизацию вовремя
- **Exception:** Общие ошибки (QR-код не найден, проблемы с браузером и т.д.)

При ошибке пользователь и админ получают уведомления с описанием проблемы.
