# Осознанные решения проекта

Этот файл содержит нестандартные решения, принятые осознанно для проекта. Каждое
решение фиксирует не только результат, но и причины выбора, чтобы его не отменили
случайно при последующих изменениях.

## Правила использования

- Перед каждой задачей полностью прочитай этот файл.
- При планировании и реализации проверь, не затрагивает ли задача действующие решения.
- Не нарушай действующее решение молча. Если требования задачи с ним конфликтуют,
  укажи конфликт пользователю и предложи отдельное новое решение.
- Не редактируй принятое решение задним числом. Если решение больше не действует,
  пометь его как заменённое и добавь новую запись с объяснением изменений.
- Для каждой новой записи используй следующий шаблон.

## DEC-001 — Название решения

- **Статус:** действующее
- **Дата:** YYYY-MM-DD
- **Контекст:** какую проблему или ограничение нужно было учесть.
- **Решение:** что именно принято делать.
- **Причины:** почему выбран этот вариант.
- **Последствия и ограничения:** к чему приводит решение и что важно помнить.
- **Затронутые области:** модули, файлы или бизнес-процессы.
